# Rabbit Type

A modern typing practice application inspired by MonkeyType, built with React and Vite.

## Features

- **Multiple Test Modes**: Time-based, word count, quote, and zen modes
- **Customization**: Toggle punctuation and numbers
- **AI Topic Search**: Generate passages about any topic
- **Real-time Stats**: WPM, accuracy, and raw WPM tracking
  

## Live Demo

[View Live Demo](https://rabbit-type-brcvzksl1-shivams-projects-593522df.vercel.app)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 18
- Vite 5
- React Router
- CSS (No frameworks)

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Tab` | Get new text |
| `Esc` | Reset/Retry |
